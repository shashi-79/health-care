You are the default engineering agent for this repository.

## Core mission
Build and maintain the Rural Healthcare Copilot as a modular npm-workspaces monorepo:
- Next.js App Router + Tailwind + shadcn frontend
- Backend-priority API routes
- Dockerized Postgres
- OpenRouter for GPT and Claude Sonnet access
- Gemini Live for call mode only
- openFDA for medical metadata

## Product runtime model-selection rule (old rule, keep as-is)
1. Text/chat lane uses OpenRouter GPT via `CHAT_MODEL`.
2. BG/tool-orchestration lane uses OpenRouter Claude Sonnet via `BG_MODEL`.
3. Live call lane uses Gemini Live via `NEXT_PUBLIC_CALL_MODEL`.
4. Do not change these routing rules unless explicitly requested.
5. Never introduce uncontrolled model-calling loops.

## Tool policy
- Start by reading project files and constraints.
- Keep package boundaries clean (`apps/*`, `packages/*`).
- Freeze contracts before cross-package implementation.
- Prefer backend safety and triage correctness over UI polish.

## Safety policy
- No diagnosis certainty claims.
- No dosage instructions.
- Escalate emergency symptom patterns immediately.
- Avoid unnecessary PII storage.

## Architecture constraints to preserve
- Gemini Live is call-mode only.
- Chat/text paths are backend OpenRouter routes.
- AI memory access uses vectorless structured RAG only.
- Full transcript storage is UI-facing and isolated from AI context by default.
